## 0. 图例与阅读顺序

| 记号 | 含义 |
|---|---|
| **L1–L5** | 纵向层，**数字越大越靠近"智能与策略"，依赖严格单向向下** |
| **R** | 装配根轴（不是层）——兵种差异的唯一落点 |
| **X1–X5** | 横切面（不是层）——贯穿所有层，以契约/能力形式提供 |
| **★** | 由**三项决议**引入或变更的部分 |
| `∥` | 二者可互换 / 并存 |

**阅读顺序**：主图（结构与分层）→ 附图 A（世界模型如何形成）→ 附图 B（决策层接口）→ 附图 C（离线闭环）。

### 1.1 层职责速查

| 层 | 一句话职责 | 关键纪律 |
|---|---|---|
| **L5** | 决定"做什么" | RL 只能输出**意图**，安全包络由下层强制 |
| **L4** | 实现"怎么做到" | 每个功能 = 独立 package，可独立启停/测试/回放 |
| **L3** | 回答"世界是什么样" | 输出**唯一**的 WorldSnapshot；定位是安全关键 |
| **L2** | 屏蔽"东西怎么连" | 全部以**接口/端口**暴露，实现可替换 |
| **L1** | 提供"谁都能用的基础" | 零业务语义，被所有人依赖 |
| **R** | 决定"这一台是什么车" | 唯一允许知道全局；不含算法逻辑 |

     内置地图 ⇒ 配准残差 = "无标号的动态物体"（含己方 + 敌方 + 弹丸）

     ⇒ 敌方态势广播给步兵 ⇒ 步兵半自动攻击（操作手开火授权）

  ★ 因此哨兵天然是队伍的「态势节点」：它有地图，所以能算出"什么不该在那儿"

## 3. 附图 B：决策层接口（RL 与规则同构）

```
            WorldSnapshot（定长 · 区域离散化 · 带 age/confidence）
                              │
            ActionMask（由 L5-b 技能层计算的前置条件可行性）
                              │
                              ▼
              ┌─────────────────────────────────┐
              │   decide(world, mask)           │  ← 唯一接口
              │   (state, mask) → action        │
              └────────────────┬────────────────┘
                               │
      ┌──────────────┬─────────┴──────────┬──────────────────┐
      ▼              ▼                    ▼                  ▼
  有限状态机     行为树           效用打分(推荐起点)      RL(masked policy)
  内部状态+快照  节点端口=快照    每技能算分→mask内argmax  网络→logits→mask→采样
      │              │                    │                  │
      └──────────────┴─────────┬──────────┴──────────────────┘
                               ▼
                Decision { skill_id, params, confidence, rationale }
                               │
                               ▼
       L5-b 技能层展开 → L5-c 安全门校验 → L4 执行(自瞄/导航)

  ★ mask 进接口的三重收益：
    ① 规则与 RL 结构同构 → 可互换 · 可对比 · 可影子模式
    ② RL 的 mask 逻辑训练与部署共用同一份代码 → 消除"训练-部署不一致"
    ③ mask 即"前置条件检查"，规则侧天然复用

  ★ 关键约束（安全）：RL 输出的是"意图"，安全包络由 L5-b/L5-c 强制，不可由 RL 自觉
```

## 5. 要点速查（全部结论压缩版）

**结构**

1. **6 层 + 5 面 + 1 装配根**：L1 平台 · L2 I/O · L3 世界模型 · L4 功能 · L5 决策仲裁 · R 装配根。
2. **依赖严格单向向下**，装配根向上组合；**进 CI 校验**，否则文档写完就烂。
3. **决策分三子层**（RL 战术 / FSM-BT 技能 / 安全门），**分层依据是时间尺度分离**（1–5Hz / 10–50Hz / 100–1000Hz）。
4. **看门狗不是层**，拆入 X1：心跳 · 急停硬路径 · 定位健康 · 开火安全门。**急停走不依赖中间件的硬路径。**
5. **调试拆三处**：基础设施→L1 · 调试入口→R（独立装配根，禁 `#ifdef`）· 可视化调参→X4（外部工具）。
6. **兵种复用 = 同代码 + 新装配根 + 新 YAML**，禁止 `#ifdef`；配置两级覆盖即可。

**三项决议**

7. **内置地图 + 激光仅定位** ⇒ 删除地形感知整链；**定位升级为安全关键服务**（带置信度/新鲜度）。
8. **地图是契约资产**：2D 栅格与 3D 点云必须同源同坐标系；**原点全队统一**（兵间共享的前提）。
9. **配准残差 = 动态障碍**（免费得到）；减去队友广播的位置 ⇒ 敌方态势 ⇒ 闭环成立。
10. **共享"态势语义"而非原始点云**；最终一致 + TTL + 置信度；机间通信**绝不在实时路径上**。
11. **决策接口 = `(WorldSnapshot, ActionMask) → Decision`**；`mask` 必须进接口，使规则与 RL 结构同构。
12. **状态设计**：定长 · **区域离散化** · 带 age/confidence · 纯函数零 ROS · 仿真可复现。
13. **RL 只输出意图**，安全包络由下层强制；训练时也必须施加 mask 与观测噪声。
14. **步兵开火必须人工授权** ⇒ 安全落点转移为：**禁止把友军作为瞄准目标** + **呈现保真**；
    **IFF 取保守取向（宁可漏报，不可误报）**；**授权绑定目标身份，目标切换即失效**。
15. **RL 当红队，不当控制器**：不需要 sim2real，产出是可沉淀的规则；控制器上线不做。

**效率**

16. **实时域划分**：硬实时（去中间件、独立线程、禁动态分配）/ 软实时（进程内组合 + 零拷贝）/ 非实时。
17. **QoS 档位化**（2–3 个命名档位），不随手写；**执行器与回调组显式配置**。
18. **关键路径保留"去 ROS 化"能力**（算法与 ROS 分离）。

**开发**

19. **先定接口，后定算法**——接口对了，打分函数与神经网络可互换。
20. **三份契约优先冻结**：世界模型接口 · 决策产物接口 · 机间态势协议。
21. **轻量对局仿真不需要物理引擎**（区域级随机博弈），这是整个计划可行的关键。
22. **赛后数据最高价值是校准仿真**（system identification），不是直接训 RL（数据量不够 + 分布偏移）。
23. **必须先过的门槛检验**：把规则基线放进仿真，看胜负率是否与实车相符。仿真不可信 ⇒ RL 不可信。
